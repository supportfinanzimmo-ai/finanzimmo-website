⬇ Imura Testversion laden

So startest du

  1. ZIP entpacken: Rechtsklick auf die geladene Datei → Alle extrahieren… → z. B. nach C:\Programme-Test\Imura.
  2. App starten: Im entpackten Ordner doppelt auf finanz_immo_app.exe klicken.
  3. Windows-Warnung: Es erscheint „Der Computer wurde durch Windows geschützt“. Das ist normal, weil die Testversion noch nicht signiert ist. Klicke auf Weitere Informationen → Trotzdem ausführen.
  4. Ausprobieren: Beim ersten Start durch die Willkommensseiten klicken und „Mit Beispieldaten ausprobieren“ wählen. So siehst du alle Bereiche sofort gefüllt.
  5. Eigene Daten (optional): Später unter Profil → „Neues Profil anlegen“ ein eigenes Profil mit PIN anlegen.
  6. Feedback geben: Unten rechts in der App ist ein gelber Feedback-Knopf. Ein Screenshot hilft sehr: Windows + Umschalt + S.
